# EMEGShelper

Contains some channel information and functions that I found helpful for working with the EMEGS particularily with data recording during my Graduate work at UGA. 

## How to install package in R:
`remotes::install_github("AndrewHFarkas/EMEGShelper")`

## To look at the functions inside of the package in R, use double colons after the package name and press tab to see autocomplete options
`EMEGShelper::`

## To see documentation of a function, put the `?` before the function. For example:
`?EMEGShelper::read_ar_file`

## To see the source code, enter the function in the console without the parentheses
`EMEGShelper::read_ar_file`
